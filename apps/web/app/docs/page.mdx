# Product Helper documentation

Product Helper is a portable Agent Skill for evidence-based planning, architecture decisions, repository improvement, and production-readiness review.

## What it does

- **Plan** a new project from constraints, feasibility, and trade-offs.
- **Improve** an existing repository from inspected evidence.
- **Review** a project before deployment and prioritize its risks.

## What it does not do

Product Helper does not provide an AI backend, account system, database, telemetry service, or automatic project changes. Your coding agent remains responsible for reasoning and for actions that require authorization.

## Start here

Install the skill, restart or refresh your host agent, then invoke it with a practical engineering question.

```text
$product-helper Help me decide the first milestone for this project.
```
