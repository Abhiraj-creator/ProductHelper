# Getting started

Product Helper works inside supported coding agents. It supplies the methodology; the agent supplies reasoning, repository access, and available tools.

## Supported agents

- Codex
- Claude Code

## First use

```text
$product-helper Review this application before production deployment.
```

For a substantial request, expect evidence labels, trade-offs, practical next actions, and a check that can disprove the recommendation.
