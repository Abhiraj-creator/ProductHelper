# Review before launch

Use the review workflow for a complete or nearly complete project. Product Helper assesses readiness against intended users, data, traffic, deployment, security, operations, and recovery expectations.

```text
$product-helper Review this project before deployment.
```

The output prioritizes evidence-based risks, practical mitigations, and validation steps. It is advisory; it does not certify security or compliance.
