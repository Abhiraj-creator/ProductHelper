# Plan a new project

Use the plan workflow when the project is an idea or has no implementation yet.

Product Helper identifies the constraints that could change the decision, then recommends the smallest credible build direction.

```text
$product-helper I want to build a SaaS for managing freelance projects.
```

The result can include a feasible scope, architecture direction, roadmap, first vertical slice, and material risks.
