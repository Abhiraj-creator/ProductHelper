# Contributing

Product Helper is open source. Contributions that improve workflow quality, agent compatibility, tests, examples, or documentation are welcome.

## Repository areas

- `skills/product-helper/` is the portable runtime skill.
- `packages/cli/` is the npm installer and manager.
- `apps/web/` is the official documentation website.

Keep the website's CLI commands and agent paths aligned with the implementation. Small, evidence-backed changes are easier to review and maintain.
