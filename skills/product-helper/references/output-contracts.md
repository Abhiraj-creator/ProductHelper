# Output contracts

Read when producing a substantial deliverable. Use the shortest contract that fits the request.

## Pre-build

Include the recommendation and constraint fit, assumptions and evidence, main alternative and trade-offs, architecture direction, phased roadmap, first useful slice with proof, risks, and next action.

## Mid-build

Include inspection scope, observed current architecture, prioritized findings, what to keep/change/defer, affected areas, dependencies, acceptance behavior, focused validation, failure or rollback considerations, and remaining unknowns.

## Post-build

Include release target, inspection limits, prioritized findings, and for each finding: explicit severity, evidence, impact, recommended fix, and validation. Distinguish must-fix, should-fix, and defer. State what the review cannot certify.

## Decision or narrow advice

Answer the requested shape. Include constraint fit, assumptions, main alternative, material trade-offs, and a proportionate next check without expanding into an unnecessary project report.
